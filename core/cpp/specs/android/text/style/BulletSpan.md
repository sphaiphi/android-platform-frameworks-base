# BulletSpan - Reverse Engineering Documentation

## Executive Summary
Paragraph style that adds a bullet point at the start.

## Properties
- **`mGapWidth`**: Gap between bullet and text.
- **`mColor`**: Bullet color.
- **`mBulletRadius`**: Radius.

## Java-to-C++ Translation Guide
- **Layout**: Implements `LeadingMarginSpan`. Renders the bullet in the margin.
