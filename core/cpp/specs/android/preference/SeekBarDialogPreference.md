# SeekBarDialogPreference - Reverse Engineering Documentation

## Executive Summary
`SeekBarDialogPreference` is a base class for preferences that show a SeekBar in a dialog.

**Note:** This class is deprecated and hidden.

## Architecture Overview
- **Inheritance**: `SeekBarDialogPreference` -> `DialogPreference`.

## Detailed Functionality
-   **Icon**: Displays an icon in the dialog.
-   **Buttons**: Sets OK/Cancel buttons.
