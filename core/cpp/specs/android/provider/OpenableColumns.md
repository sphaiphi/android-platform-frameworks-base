# OpenableColumns - Reverse Engineering Documentation

## Executive Summary
`OpenableColumns` defines standard columns (`DISPLAY_NAME`, `SIZE`) for content providers that serve files.

## Architecture Overview
- **Type**: Interface (Constants).

## Data Model
-   `DISPLAY_NAME`: `_display_name` (String).
-   `SIZE`: `_size` (Long).

## Java-to-C++ Translation Guide
-   **Strings**: String constants.
