# TranslationSpec - Reverse Engineering Documentation

## Executive Summary
Defines the language and data format for a translation operation.

## Data Model
*   **Locale**: `ULocale` (ICU locale).
*   **Format**: `DATA_FORMAT_TEXT` (1).

## Java-to-C++ Translation Guide
*   **Locale**: `ULocale` corresponds to ICU4C `icu::Locale`.
