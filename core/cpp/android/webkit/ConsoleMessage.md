# ConsoleMessage - Reverse Engineering Documentation

## Executive Summary
`ConsoleMessage` encapsulates a JavaScript console message (log, warning, error, etc.) generated by a web page. It is passed to `WebChromeClient#onConsoleMessage`.

## Architecture Overview
*   **Role**: Data holder for console logs.
*   **Enums**: `MessageLevel` (TIP, LOG, WARNING, ERROR, DEBUG).

## Detailed Functionality
*   **Fields**: Message text, source ID (filename/URL), line number, message level.

## Java-to-C++ Translation Guide
*   **Struct**: Can be mapped to a simple C++ struct or class holding the string and integer fields.
*   **Enum Mapping**: Map `MessageLevel` to the C++ console logging levels.
