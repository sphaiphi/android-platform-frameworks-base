# TriggerEvent - Reverse Engineering Documentation

## Executive Summary
`TriggerEvent` is a data container for events generated by one-shot trigger sensors (e.g., `TYPE_SIGNIFICANT_MOTION`). It contains the sensor values and the timestamp of the event.

## Architecture Overview
Similar to `SensorEvent`, but simplified for one-shot delivery. The associated sensor is automatically disabled after the event is delivered.

## Detailed Functionality

### Values
- For `TYPE_SIGNIFICANT_MOTION`, `values[0]` is always 1.0.

## Data Model
- `values` (float[]): Data payload.
- `sensor` (Sensor): Source.
- `timestamp` (long): Nanoseconds.

## Java-to-C++ Translation Guide
- **Class**: `class TriggerEvent` -> `struct TriggerEvent`.
- **Timestamp**: Use `int64_t`.
