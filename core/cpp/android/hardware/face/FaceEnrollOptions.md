# FaceEnrollOptions - Reverse Engineering Documentation

## Executive Summary
`FaceEnrollOptions` is a configuration class for face enrollment requests. It is a Parcelable data class generated by the `DataClass` utility. Currently, it primarily holds the enrollment reason.

## Architecture Overview
- **Type**: Data Class / Parcelable.
- **Generation**: Generated via `codgen`.

## Detailed Functionality
- **Fields**:
    - `mEnrollReason` (`int`): The reason for enrollment (UNKNOWN, RE_ENROLL_NOTIFICATION, SETTINGS, SUW). Default: UNKNOWN.

## Constants (EnrollReason)
- `ENROLL_REASON_UNKNOWN` (0)
- `ENROLL_REASON_RE_ENROLL_NOTIFICATION` (1)
- `ENROLL_REASON_SETTINGS` (2)
- `ENROLL_REASON_SUW` (3)
