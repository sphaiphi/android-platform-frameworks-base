# FaceServiceReceiver - Reverse Engineering Documentation

## Executive Summary
`FaceServiceReceiver` is an abstract base class (or adapter) that extends `IFaceServiceReceiver.Stub` and provides empty default implementations for all callback methods.

## Architecture Overview
- **Type**: Abstract Callback Adapter.
- **Implements**: `IFaceServiceReceiver` (AIDL).
- **Purpose**: Allows callers to subclass and override only specific methods they care about, rather than implementing the entire AIDL interface.

## Detailed Functionality
- All methods (`onEnrollResult`, `onAcquired`, `onAuthenticationSucceeded`, etc.) have empty bodies.

## Java-to-C++ Translation Guide
- **Inheritance**: Inherit from `BnFaceServiceReceiver` (generated by AIDL compiler in C++).
- **Usage**: Useful base class for C++ clients as well to avoid implementing unused virtual methods if the AIDL C++ backend doesn't provide default no-ops.
