# FillResponse (Augmented) - Reverse Engineering Documentation

## Executive Summary
`FillResponse` (Augmented) contains the response to an augmented autofill request, specifically focusing on Inline Suggestions (as custom UI is handled via `FillController`/`FillWindow`).

## Data Model

### Fields
*   `mFillWindow`: `FillWindow` - (Nullable) The window used for UI.
*   `mInlineSuggestions`: `List<Dataset>` - (Nullable) Inline suggestions to display on the keyboard.
*   `mClientState`: `Bundle` - State for future requests.

## API Reference

### Builder (`FillResponse.Builder`)
*   `setFillWindow(FillWindow)`
*   `setInlineSuggestions(List<Dataset>)`
*   `addInlineSuggestion(Dataset)`
*   `setClientState(Bundle)`

## Java-to-C++ Translation Guide

### Data Class
*   **Java**: Generated by `DataClass`.
*   **C++**: Struct/Class to hold these fields.

### Dependencies
*   `FillWindow` (Augmented specific), `Dataset` (Standard Autofill), `Bundle`.

## Implementation Notes
*   **Inline Suggestions**: The primary way to return data if not drawing a custom window.
