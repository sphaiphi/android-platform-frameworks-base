# TextLinksParams - Reverse Engineering Documentation

## Executive Summary
Configuration for *applying* `TextLinks` to a `Spannable`. Controls how spans are created (`SpanFactory`) and applied (`ApplyStrategy` - replace or ignore existing).

## Key Methods
*   `apply(Spannable, TextLinks)`: Iterates links and applies spans to the text.
