# AutofillManagerInternal - Reverse Engineering Documentation

## Executive Summary
Abstract class for the local system service interface of AutofillManager. Used for in-process communication within the system server (e.g., from ActivityManager).

## Key Methods
*   `onBackKeyPressed`: Notify back press.
*   `getAutofillOptions`: Get options for a package.
