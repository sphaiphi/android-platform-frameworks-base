# LeadingMarginSpan - Reverse Engineering Documentation

## Executive Summary
Interface for paragraph styles that add a margin (indent) to the start of lines.

## API Reference
- **`getLeadingMargin(first)`**: Returns pixel width.
- **`drawLeadingMargin`**: Renders content in the margin.

## Java-to-C++ Translation Guide
- **Layout**: Critical for bullet points, quotes, indents.
