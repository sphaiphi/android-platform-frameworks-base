# BiometricStateListener - Reverse Engineering Documentation

## Executive Summary
`BiometricStateListener` is an abstract class (implementing an AIDL stub) used to listen for state changes in biometric sensors. It allows system components to monitor if sensors are enrolling, authenticating, or idle.

## Architecture Overview
It extends `IBiometricStateListener.Stub`, making it a Binder object that can be passed to the system service.

## Detailed Functionality

### States (`State`)
- `STATE_IDLE` (0)
- `STATE_ENROLLING` (1)
- `STATE_KEYGUARD_AUTH` (2)
- `STATE_BP_AUTH` (3): BiometricPrompt auth.
- `STATE_AUTH_OTHER` (4)

### Actions (`Action`)
- `ACTION_SENSOR_TOUCH` (0): Sensor was touched.

### Callbacks
- `onStateChanged(int newState)`
- `onBiometricAction(int action)`
- `onEnrollmentsChanged(int userId, int sensorId, boolean hasEnrollments)`

## Java-to-C++ Translation Guide
- **Binder**: Inherit from `BnBiometricStateListener` (generated by AIDL compiler).
- **Callbacks**: Implement virtual methods.

## Implementation Risks
- Binder threading: Callbacks come in on binder threads.
