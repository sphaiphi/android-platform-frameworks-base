# IFingerprintService - Reverse Engineering Documentation

## Executive Summary
`IFingerprintService` is the main AIDL interface for the Fingerprint Service.

## Architecture Overview
- **Type**: AIDL Interface.
- **Permissions**: Annotated with permissions (e.g., `USE_BIOMETRIC_INTERNAL`, `MANAGE_FINGERPRINT`).
