# Implementation Plan: ViewPropertyAnimator

**Branch**: `002-view-property-animator` | **Date**: 2026-06-05
**Preceded by**: [001-window-manager plan](../001-window-manager/plan.md)

## Summary

Implement `ViewPropertyAnimator` — a fluent, optimized animation API for animating select properties on `View` objects (alpha, translationX, translationY, rotation, scaleX, scaleY). The animator batches multiple property changes into a single Choreographer-driven frame callback.

**Scale**: 4 new files + 2 modified, ~600-900 lines total. **Committed**: `6c1d2dba`
